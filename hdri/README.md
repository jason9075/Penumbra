# HDRI Assets

Equirectangular Radiance HDR (`.hdr`) environment maps, 1k resolution (1024×512),
downloaded from [Poly Haven](https://polyhaven.com/hdris).

## Assets

| File | Scene | Author | Source |
|---|---|---|---|
| `royal_esplanade_1k.hdr` | Bright indoor mall, cool ceiling light with warm spots | Greg Zaal | https://polyhaven.com/a/royal_esplanade |
| `venice_sunset_1k.hdr` | Outdoor sunset over Venice waterfront | Greg Zaal | https://polyhaven.com/a/venice_sunset |
| `moonless_golf_1k.hdr` | Night sky with Milky Way over a golf course | Greg Zaal | https://polyhaven.com/a/moonless_golf |

Higher resolutions (up to 16k) are available at each source link — swap the
`1k` suffix in the download URL, e.g.
`https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/2k/venice_sunset_2k.hdr`.
